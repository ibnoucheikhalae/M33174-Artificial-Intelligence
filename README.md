## How to Run
To run this code you first need the following software installed:
- python
- numpy
- matplotlib

Luckily, if you have python already we have made the second step easy for you by providing an initialisation script :)  
This script will create a virtual environment and automatically download those requirements into it for you. All you have to do is run the following commands (assuming you're on a unix-based system):

```
./init.sh
source venv/bin/activate
```
